# История версий

Снимки версий лежат в `_релизы/<версия>/` (локально, в репозиторий не загружаются).

## 0.8.0 — 2026-09-27 (зафиксирована) — P0 из `docs/План_доработок.md`

**P0-1. Уроки класса подряд, без окон**
- Генератор ставит урок туда, где он не добавляет окон в день класса; окно — только если иначе урок не встаёт. После расстановки окна закрываются переносом более позднего урока того же дня.
- Из 40 попыток берётся та, где меньше неразмещённых, при равенстве — меньше окон.
- Над сеткой — итоги: не размещено, окон у классов, конфликтов учителей, закреплено, ручных правок без замка. Бот сообщает число окон.
- На тестовой школе (18 классов, 44 учителя): было 48 окон и 13 дней не с 1-го урока, стало 0 и 0.

**P0-2. Расписание не стирается при правках**
- Правка данных помечает расписание «устарело — перестройте»; убираются только невозможные ячейки (класс удалён, предмет убран из плана, пропал день или урок) — с сообщением, сколько убрано.
- Учитель урока следует за планом; удалённый кабинет снимается с урока. Галочки предметов у учителя расписание не трогают.
- Ручная правка ячейки помечается; перед перестроением — «Ручных правок без замка: N»: закрепить и перестроить / перестроить всё / отмена (и в мастере, и в боте).
- «Очистить расписание» — с подтверждением.
- Удаление учителя снимает его назначения в планах (дефект Д-1).

**P0-3. Надёжная выгрузка Excel**
- Имена листов уникальны (« (2)», « (3)»…); класс без сетки пропускается; ячейки читаются с проверкой границ.
- При сбое — сообщение, а не тишина. Пустое название класса и имя учителя не сохраняются.

**P0-4. Защита данных в браузере**
- Запись только при изменении данных, а не на каждую перерисовку.
- Хранилище не принимает запись — при открытии страницы ничего не показывается; после первой несохранённой правки — спокойная подсказка «сохраните копию настроек в файл» (в облаке claude.ai — не показывается).
- Нечитаемое сохранение откладывается в `timetable_builder_v4_corrupt` и доступно для скачивания; не затирается.
- Открыта вторая вкладка — первая становится «только для чтения» с кнопкой «Обновить».

**P0-5. Аналитика**
- Каталог событий `EVENT_CATALOG`: параметры вне каталога и строки не-коды отбрасываются — ФИО, названия классов и предметов в события не попадают.
- Ко всем событиям — анонимный `install_id` и код школы из ссылки `?school=`.
- Новые события: `app_open`, `milestone` (воронка), `generate_blocked`, `issue_fix_click`, `generate_result`, `schedule_invalidated`, `storage_error`, `multi_tab_detected`, `js_error`, `import_json_result`.
- По результату вместо попытки: `export_xlsx` → `export_xlsx_result`, `staff_import` → `staff_import_result`, `schedule_generate` → `generate_result`. `bot_start` — с первого показа; `tab_open` — и при переходах из бота и по «Исправить →».
- Вебвизор Метрики выключен явно.

**P0-6. Групповые уроки**
- У каждой группы свой кабинет; вместимость — по размеру группы (поле «чел.», пусто — половина класса).
- Один учитель в обеих группах — ошибка до генерации. Блок у пары групп общий.

**P0-7. Параллель класса**
- Параллель можно менять всегда; смена дней, уроков или параллели у класса с расписанием не роняет генерацию и выгрузку.

**Тесты:** `tests/browser/smoke.js` — 78 проверок (было 32), новые кейсы ПМИ: T-2-20…22, T-6-25…27, T-8-22, 23, 26, 27, T-10-10, T-12-11…15, T-13-01…04, 06. Для запуска рядом с `devserver.py` добавлена конфигурация `static` (порт 8767) в `.claude/launch.json`.

## 0.7.0 — 2026-09-26 (зафиксирована)

**Учебный план по приказам**
- Встроены планы приказов МНиШО №183 (10–11, 16 таблиц) и №227 (7–11, 72 таблицы), извлечённые из PDF автоматически с проверкой сумм (`tools/npa`).
- У класса 7–11 — поле «Направление»: базовый план / приказ №183 (только критериальная школа) / приказ №227.
- Языки обучения: добавлены казахский, киргизский, таджикский, туркменский; для них — «образец плана» (с русским языком / без).
- Автозаполнение по базовой сетке доступно любой школе; класс запоминает, по какому документу заполнен план (`appliedPlan`).

**Интерфейс**
- Закрепление урока: контурные значки замка вместо эмодзи, формулировки «закрепить / открепить», закреплённая ячейка — синяя рамка.
- Цвета групп предметов в сетке, в виде «По учителям» и в плане; легенда.
- Подписи всех шагов видны всегда; на телефоне степпер прокручивается к текущему шагу.
- Стиль в тренде eMaktab: белая страница, карточки с рамкой, плашки со значками, бейджи статусов, выбор класса рамкой.
- Тёмная тема удалена.

**Архитектура и качество**
- Проверки перед генерацией возвращают коды (`Issue{code, params}`), текст — при показе.
- Данные приказов вставляются в страницу скриптом между маркерами `ORDER_PLANS:BEGIN/END`, с версией.
- Сквозные проверки в браузере: `tests/browser/smoke.html` (32 проверки).
