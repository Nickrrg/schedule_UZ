# Учебные планы из приказов (НПА) → данные для index.html

Таблицы учебных планов приказов МНиШО №227 (26.06.2026, вариативные планы 7–11) и №183 (25.05.2026, предметы по выбору 10–11) извлекаются из PDF автоматически и встраиваются в `index.html` как `ORDER_PLANS`. Руками данные не правятся — только пересборкой.

## Когда нужно

Вышел новый приказ или новая редакция — положите PDF в папку `НПА/` и пересоберите.

## Как пересобрать

1. Запустить сервер из корня проекта:
   ```bash
   py tools/npa/devserver.py
   ```
2. Открыть в браузере `http://localhost:8766/tools/npa/pdftext.html` и в консоли разработчика выполнить:
   ```js
   const a = await extractTables('/НПА/227_buyruq_variativ_reja.pdf', '227');
   const b = await extractTables('/НПА/www.idum.uz__tanlov_fanlar_183_2026-2027.pdf', '183');
   a.filter(t => t.issues.length); b.filter(t => t.issues.length);   // проверка сумм
   await saveJson('tables_227.json', a); await saveJson('tables_183.json', b);
   ```
   Таблицы сохранятся в `tools/npa/out/`. PDF читается библиотекой pdf.js (грузится с cdnjs).
3. Собрать данные:
   ```bash
   py tools/npa/build_plans.py
   ```
   Скрипт печатает сводку (направления, языки, все названия предметов) и пишет `tools/npa/out/order_plans.js`.
4. Вставить данные в страницу (заменяет блок между маркерами `ORDER_PLANS:BEGIN` и `ORDER_PLANS:END`; повторный запуск без изменений данных файл не меняет):
   ```bash
   py tools/npa/build_plans.py --inject index.html
   ```
   Если вышла новая редакция приказа — поправить дату в `meta` в `build_plans.py`: по ней класс запоминает, по какой версии заполнен план.
5. Прогнать `tests/browser/smoke.html` (проверка итогов всех таблиц — T-6-24).

## Как проверяется извлечение

- Колонки классов определяются по координатам заголовка таблицы (VII…XI или 10 11), поэтому пустые ячейки не сдвигают значения.
- Для каждой таблицы сверяются суммы: строки части плана = строке «Jami», сумма по классам = колонке «Haftalik umumiy soat». На 26.06.2026: 72 таблицы №227 и 16 таблиц №183 без расхождений. Единственное допустимое расхождение — таблицы с шестью вторыми иностранными языками: это альтернативы, выбирается один.
- Сопоставление узбекских названий с предметами ЕСП — `ORDER_SUBJECT_RU` в `index.html`. Если в новом приказе появится предмет, которого там нет, он попадёт в план под узбекским названием; `build_plans.py` печатает полный список названий — сверьте его.

## Файлы

| Файл | Что делает |
|---|---|
| `devserver.py` | Раздаёт проект и принимает `POST /save` — сохраняет JSON из браузера в `out/` |
| `pdftext.html` | Страница с pdf.js: `extract()` — текст страниц, `render()` — картинка страницы |
| `extract.js` | `extractTables()` — таблицы с проверкой сумм, `saveJson()` |
| `build_plans.py` | Сборка компактного `ORDER_PLANS` |
| `out/` | Результаты (JSON таблиц и `order_plans.js`) |
