# История версий

Снимки версий лежат в `_релизы/<версия>/` (локально, в репозиторий не загружаются).

## 0.7.0 — 2026-09-26 (зафиксирована)

**Учебный план по приказам**
- Встроены планы приказов МНиШО №183 (10–11, 16 таблиц) и №227 (7–11, 72 таблицы), извлечённые из PDF автоматически с проверкой сумм (`tools/npa`).
- У класса 7–11 — поле «Направление»: базовый план / приказ №183 (только критериальная школа) / приказ №227.
- Языки обучения: добавлены казахский, киргизский, таджикский, туркменский; для них — «образец плана» (с русским языком / без).
- Автозаполнение по базовой сетке доступно любой школе; класс запоминает, по какому документу заполнен план (`appliedPlan`).

**Интерфейс**
- Закрепление урока: контурные значки замка вместо эмодзи, формулировки «закрепить / открепить», закреплённая ячейка — синяя рамка.
- Цвета групп предметов в сетке, в виде «По учителям» и в плане; легенда.
- Подписи всех шагов видны всегда; на телефоне степпер прокручивается к текущему шагу.
- Стиль в тренде eMaktab: белая страница, карточки с рамкой, плашки со значками, бейджи статусов, выбор класса рамкой.
- Тёмная тема удалена.

**Архитектура и качество**
- Проверки перед генерацией возвращают коды (`Issue{code, params}`), текст — при показе.
- Данные приказов вставляются в страницу скриптом между маркерами `ORDER_PLANS:BEGIN/END`, с версией.
- Сквозные проверки в браузере: `tests/browser/smoke.html` (32 проверки).
