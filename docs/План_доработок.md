| **P0-6** | **Групповые уроки.** Группам — разные кабинеты; вместимость — по размеру группы; один учитель в обеих группах — ошибка до генерации; «блок» у пары групп синхронизирован | Две группы информатики в один слот получают разные компьютерные классы; группа 15 чел. встаёт в кабинет на 15 мест; конфликт учителя в паре не создаётся генератором | ФТ-6.3; UX §2.2 п.7–8 | 1–2 |
| **P0-7** | **Параллель класса можно менять всегда**; смена дней или параллели у класса с расписанием не роняет генерацию и выгрузку | Класс с угаданной импортом параллелью исправляется без удаления; закреплённый субботний урок у ставшего 5-дневным класса убирается с сообщением | ФТ-2.3; UX §2.2 п.4, 9 | 0,5 |

## P1 — в пилоте (≈ 5–7 недель)

| ID | Доработка | Критерии приёмки | Связь | Оценка |
|---|---|---|---|---|
| **P1-1** | **Шаг «Нагрузка».** Таблица параллели «предмет × классы», учитель выбирается с поиском из всех учителей (сначала те, кто уже ведёт предмет); «→ на всю параллель»; «подставить известных учителей»; счётчик часов учителя против его возможностей; предметы учителя выводятся из назначений — отмечать заранее не нужно | Назначение учителей для школы на 30 классов — ≤ 90 действий (сейчас ≈ 450 выпадающих списков); ошибка «никто не ведёт предмет» не возникает из-за неотмеченной галочки | UX §1.1, U-2, U-3; ФТ-6.1.6, 6.1.8, 4.1.6 | 5–7 |
| **P1-2** | **Бот — 5 экранов.** 1) тип школы и число классов по всем параллелям на одном экране (счётчики −/+, до 15); 2) режим «1–4» и «5–11» одной таблицей со значениями по умолчанию; 3) импорт учителей; 4) план заполняется сам (только пустые), итог и переход в «Нагрузку»; 5) составить. Шаг бота сохраняется при перезагрузке; повторный проход не удаляет классы с правками без подтверждения со списком | До первого расписания — 5–6 нажатий (сейчас 22); после перезагрузки бот продолжает с того же шага | UX U-4…U-7; ФТ-11.4, 11.5 | 3 |
| **P1-3** | **Мастер — 4 шага:** Классы и режим → Нагрузка → Расписание → Выгрузка; «Справочники» (Учителя, Предметы, Кабинеты) — отдельно; **степпер показывает готовность** шага (✓ / ! / пусто) | Новичок проходит путь без лишних шагов; видно, что не заполнено | UX U-1, U-10; ФТ-1.3 | 2 |
| **P1-4** | **Уроки по дням.** У параллели и класса — «разное по дням»: например «Пн 6, Вт–Пт 5, Сб 4»; наследование класс → параллель; сетка, ось смен, проверки ёмкости и выгрузка учитывают день | Пример заказчика: у класса параллели с 5 уроками — 6-й урок в понедельник, без фиктивных предметов; короткая суббота | UX §2.1; ФТ-2.2.2, 2.3 | 3–4 |
| **P1-5** | **Правила предмета до генерации:** «не ставить на уроки …», «всегда: день, урок» (например, «Воспитание — Пн, 1-й урок», «Физкультура — не 1-м»); действуют на всю школу | Правила соблюдаются генератором без закрепления вручную; невыполнимое правило — причина в неразмещённых | UX §2.3 «Правила качества» | 3 |
| **P1-6** | **Помощь в дорасстановке:** причина у каждого неразмещённого урока («учитель занят / выходной / максимум в день», «нет свободного кабинета», «у класса нет места», «правило предмета»); «Поставить» — подсветка допустимых ячеек и установка кликом; обмен двух уроков перетаскиванием; при ручной правке подбирается кабинет | Завуч расставляет последние уроки без перебора выпадающих списков; кабинет не теряется | ФТ-8.3.2, 9.4; Д-5, Д-9 | 4–5 |
| **P1-7** | **План:** «Заполнить все классы» (только пустые); копирование плана класса на классы параллели (с учителями или без); подсказка «план не соответствует источнику» с кнопкой обновления (по `appliedPlan`) | Параллель из 5 классов заполняется одним действием; смена направления не оставляет план по старому приказу незаметно | ФТ-6.1.7, 2.3.3 | 2 |
| **P1-8** | **Импорт «Сотрудников»:** предпросмотр с отметками; фильтр по должности (колонка читается, но не сохраняется); поиск строки заголовков и узбекские заголовки; кириллица/латиница в буквах классов («5-А» = «5-A»); однофамильцы — отмечены в предпросмотре | Повар и охранник не попадают в учителя; дубли классов не создаются | ФТ-4.2.4, 4.2.6; UX §2.2 п.11 | 2 |
| **P1-9** | **Классы:** буквы по языку обучения (А, Б, В для русских классов); бот — больше 6 классов в параллели | Русская школа получает «5-А, 5-Б» | UX §2.2 п.14 | 1 |
| **P1-10** | **Учителя:** без молчаливого лимита «5 уроков в день» (пустое поле — без ограничения, очистка поля не превращается в 1); нагрузка против возможностей с учётом выходных; поиск учителя; номер урока в смене в виде «По учителям» и в выгрузке | Учитель двух смен не теряет уроки из-за значения по умолчанию | ФТ-4.1.5, 7.3, 9.8; Д-6 | 2 |
| **P1-11** | **Звонки и печать:** время уроков по сменам (начало, длительность, перемены, большая перемена); время в сетке, виде учителя и выгрузке; печать А4: класс, учитель, шахматка всех классов; лист «Все классы» в Excel | Стенд и личное расписание учителя печатаются без правки в Excel | ФТ-2.4.3, 10.2, 10.5 | 3 |

**Из P1 сознательно вынесено** (в P2 или по отдельному решению):
- уроки по дням в режиме диапазона «5–6, длинных дней не больше K» — день выбирает генератор (усложняет генератор; фиксированный профиль P1-4 закрывает пример заказчика);
- отдельный максимум уроков для каждой смены — заменён на «без молчаливого лимита» (P1-10);
- план 1–4 классов — **нужен документ** с базовым учебным планом 2026–2027 (получен: приказ №133, сделано в 0.11).
