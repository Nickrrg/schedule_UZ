- **Сделано:** P0 (0.8), P1 (0.9), этап 1 пилота (0.10, зафиксирована) — загрузка из eMaktab, проверка, сверка с учебным планом, сквозная нумерация уроков; 0.11 — правила школы и дни профразвития (ФТ-18), перенос в eMaktab (ФТ-19), приказ №133 (ФТ-20), фокус на старте (ФТ-21). 210 автопроверок.
- **Дальше:** показ 0.11 и фиксация → консьерж-тест на 2 школах → перестроение с минимумом изменений → флоу четверти → фаза 0 архитектуры.

## Правила для документов
- Требование меняется — правится ТЗ (статус «есть (версия)»), тест — ПМИ и `tests/browser/smoke.js`, запись — `CHANGELOG.md`.
- Решение пользователя по продукту — в документ пилота (разделы 8–9) или в ТЗ с датой.
- Реальные данные школ (`дано/`) не цитировать в документах с ФИО.
