## Состояние на 0.12.0 (зафиксирована 2026-10-03)
- **Сделано:** P0 (0.8), P1 (0.9), этап 1 пилота (0.10) — загрузка из eMaktab, проверка, сверка с планом, сквозная нумерация; 0.11 — правила школы (ФТ-18), перенос в eMaktab (ФТ-19), приказ №133 (ФТ-20), помощник и конструктор на разных экранах (ФТ-21); **0.12 — новая структура (ФТ-22):** конструктор с меню слева, таблицы и боковая панель, отдельные «Сетка» и «Проверка», помощник «проверить / с нуля» с экраном «О школе». 407 автопроверок; прогон на двух реальных школах (50 и 188 классов) — пройден.
- **Дальше:** загрузка 0.12 на GitHub → показ завучам → разбор «Будущих задач» (`План_доработок.md`) → этап 2 (перестроение с минимумом изменений) → фаза 0 архитектуры. Порядок работы — `Процесс_разработки.md`.
- **Решения продукта:** интеграция с eMaktab, авторизация и серверное хранение — после пилота; хостинг — на стороне eMaktab; аналитика в пилоте обязательна (состав — от аналитика).

## Правила для документов
- Требование меняется — правится ТЗ (статус «есть (версия)»), тест — ПМИ и `tests/browser/smoke.js`, запись — `CHANGELOG.md`.
- Решение пользователя по продукту — строкой в `Журнал_решений.md` (дата, решение, почему); замечания — в документ пилота, раздел 8.
- Реальные данные школ (`дано/`) не цитировать в документах с ФИО.
